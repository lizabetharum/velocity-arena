16-day curriculum
One question · one loop · five floors
The whole program is one question

How can you use data, equations, and code to build a robot athlete that wins on math, not luck?

The loop — every match day, the same 4 steps

Predict→ Run→ Gap→ Recover

Predict with a formula before the match · Run it · write the Gap sentence (predicted / did / gap as a number) · Recover — every losing team, before its next match. The math changes each week; the loop never does.

Underwater? Protect these five

  1. Predict before each match
  2. Gap sentence after each match
  3. Loss recovery after every loss
  4. Students explain the math — not you
  5. ENDS closure to end the day

If only these five happen, you ran the day right. Cut the extended debrief before you cut any of them.

Read the notes as prep — teach from three lines

The long facilitator paragraph is for the night before, not for reading live. Shrink each activity to three lines and teach from those:

DOThe one core move.
WATCHThe one mistake to catch — what quietly breaks the activity.
EXITHow it closes — the exit ticket or check before moving on.
