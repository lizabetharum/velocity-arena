Programa de Prueba de Speed

Este programa conduce el robot recto durante 2 segundos al valor de SPEED que hayas configurado — para que puedas ver cuánto recorre a diferentes valores de motorPower. Presiona B para ciclar entre los valores de SPEED sin volver a programar.

Controles de Botones
Button A

Ejecutar la prueba

Muestra la estadística SPEED y la barra de potencia, luego conduce recto durante 2 segundos y se detiene.

Button B

Ciclar SPEED

Avanza SPEED de 1 → 2 → … → 20 → de vuelta a 1 sin volver a programar. Muestra el nuevo valor en el LED.

A + B

Parada de emergencia

Corta ambos motores de inmediato durante una ejecución. Muestra X en el LED y limpia después de 500 ms.

Button A — Ejecutar la prueba
Cargando bloques…
let currentPower = 0
let SPEED = 0
let running = false
let testStart = 0
let TEST_DURATION_MS = 0
input.onButtonPressed(Button.A, function () {
    currentPower = SPEED * 100 / 20
    basic.showString("" + (SPEED))
    basic.pause(800)
    led.plotBarGraph(
    currentPower,
    100
    )
    basic.pause(800)
    basic.clearScreen()
    basic.pause(500)
    running = true
    testStart = input.runningTime()
    CutebotPro.pwmCruiseControl(currentPower, currentPower)
    while (running && input.runningTime() - testStart < TEST_DURATION_MS) {
        CutebotPro.pwmCruiseControl(currentPower, currentPower)
    }
    CutebotPro.stopImmediately(CutebotProMotors.ALL)
    running = false
    basic.showLeds(`
        # . . . #
        . # . # .
        . . # . .
        . # . # .
        # . . . #
        `)
    basic.pause(500)
    basic.clearScreen()
})
Calcula currentPower a partir de tu estadística SPEED, muestra el número y luego la barra de potencia, luego conduce recto durante TEST_DURATION_MS milisegundos. El bucle while sigue verificando el tiempo transcurrido para que una pulsación A+B pueda salir antes. El patrón X en el LED confirma que la ejecución terminó.
Button B — Ciclar SPEED
Cargando bloques…
let SPEED = 0
input.onButtonPressed(Button.B, function () {
    if (SPEED >= 20) {
        SPEED = 1
    } else {
        SPEED += 1
    }
    basic.showString("" + (SPEED))
    basic.clearScreen()
})
Aumenta SPEED en 1 con cada pulsación — vuelve a 1 después de 20. El número desplazándose te permite confirmar el valor antes de presionar A. No es necesario volver a programar.
Button A+B — Parada de Emergencia

Establece running = false para que el bucle del Botón A salga en su próxima verificación, luego corta ambos motores de inmediato. Úsalo si el robot se dirige a un lugar donde no debería.

¿Cómo Funciona el Ciclo del Botón B?

El Botón B cambia SPEED en memoria sin tocar el programa grabado. Cada pulsación agrega 1 a SPEED. Cuando SPEED llega a 20, la siguiente pulsación lo devuelve a 1.

1 → 2 → · · · → 20 → 1 → · · ·
ℹ️
El nuevo SPEED solo surte efecto la próxima vez que presiones A. Presionar B a mitad de una ejecución cambia el valor en memoria pero no afecta la conducción actual — currentPower ya fue calculado cuando presionaste A.
Variables y Constantes
NombreValorPropósito
SPEED 1 Estadística de velocidad inicial — configura en 1 en el código antes de descargar, luego cicla con el Botón B
TEST_DURATION_MS 2000 Cuánto tiempo conduce el robot en cada pulsación de A (milisegundos). Configura esto en 2000 en el código antes de descargar
currentPower calculado (SPEED × 100)/20 — el valor PWM real enviado a ambos motores
running false Bandera que la parada de emergencia A+B establece en false, causando que el bucle de conducción salga
testStart computed Marca de tiempo (ms) cuando comienza el bucle de conducción — usada para medir el tiempo transcurrido
Cómo Usar Este Programa
  1. 1 Configura TEST_DURATION_MS en 2000 y SPEED en 1 en el código. Luego descarga el programa.
  2. 2 Configura un SPEED con el Botón B. Cada pulsación agrega 1. El número desplazándose confirma el valor actual. Deténte cuando llegues a la estadística que quieres probar.
  3. 3 Coloca el robot en una trayectoria recta y despejada. Conduce durante 2 segundos y luego se detiene. Marca dónde comienza y dónde termina.
  4. 4 Presiona A para ejecutar. Observa la vista previa (número → barra), luego conduce. Presiona A+B en cualquier momento para detener antes.
  5. 5 Compara velocidades. Presiona B para subir SPEED, reposiciona el robot en la misma línea de inicio, presiona A de nuevo. Compara cuánto recorre.
⚠️
El robot no tiene sensores activos durante esta prueba. Conduce a ciegas durante 2 segundos. Asegúrate de que la trayectoria esté despejada — se saldrá de una mesa o chocará contra una pared sin detenerse.
