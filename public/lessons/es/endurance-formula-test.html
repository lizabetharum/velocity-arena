La fórmula de Endurance
Comprende el decaimiento — luego predice lo que hará tu bot
Fórmula de decaimiento de potencia
P(t) = 100 − (20 − E) × 1.5 × t
E = tu stat Endurance  ·  t = tiempo en minutos  ·  P(t) = % del motor en ese momento
Términos clave
P(t)Potencia del motor restante — empieza en 100%, baja con el tiempo
Endurance (E)Tu asignación de stat (1–20). Mayor E = decaimiento más lento = bot más consistente
tasa de decaimiento20 − E. Qué tan rápido se drena tu potencia cada minuto
tTiempo en minutos (0 a 3 para un partido completo)

⚠️ Dos problemas — antes de poder programar esto

La fórmula es matemáticamente correcta. Pero MakeCode no puede ejecutarla como está escrita. Dos cosas deben cambiar.

Problema 1 — El decimal (1.5)

MakeCode descarta todos los decimales en silencio. Cuando escribes 1.5, el micro:bit lee 1. Sin error. Sin advertencia. Tu tasa de decaimiento se reduce a la mitad y nunca sabrás por qué.

Solución: Reemplaza 1.5 con 3 ÷ 2. La misma matemática — pero ahora MakeCode multiplica por 3 primero y luego divide entre 2. Sin decimales en ningún lugar.
Problema 2 — Tiempo en minutos

30 segundos equivalen a 0,5 minutos. MakeCode lee 0,5 como 0. Entonces t = 0 en cada iteración del bucle. Cero por cualquier cosa es cero — nunca ocurre decaimiento. Tu bot corre a plena potencia todo el tiempo.

Solución: Mide el tiempo en segundos. MakeCode te da el tiempo en milisegundos — divide entre 1000 para obtener segundos enteros.
Transformando la fórmula

La misma predicción. Una forma nueva que el micro:bit sí puede calcular.

1
Original
P(t) = 100 − (20 − E) × 1.5 × t
Matemática correcta — rota para la computadora (decimal, tiempo en minutos)
2
Reemplaza 1.5 con 3÷2
P(t) = 100 − (20 − E) × 3 × t ÷ 2
Matemáticamente idéntico — sin decimal en ningún lugar
3
Reemplaza t (minutos) con t÷60 (segundos)
P(t) = 100 − (20 − E) × 3 × (t ÷ 60) ÷ 2
Ahora t está en segundos — un número entero que la computadora puede usar
4
Simplifica la división: 3 ÷ 2 ÷ 60 = 1 ÷ 40
P(t) = 100 − (20 − E) × t ÷ 40
Forma final. La predicción no cambia — solo una forma que la computadora puede ejecutar.

Hoja de trabajo — Antes de correr el bot
Completa tus predicciones antes de abrir MakeCode. Necesitas cuatro números — uno para cada ráfaga.

Paso 1: Encuentra tu stat Endurance y calcula la tasa de decaimiento: 20 − E

Paso 2: Sustituye cada tiempo en la fórmula para predecir endurancePercent en t = 0, 60, 120 y 180 segundos:
endurancePercent = 100 − DECAY_RATE × t ÷ 40
  • t = 0 s (inicio del partido)
  • t = 60 s (1 minuto transcurrido)
  • t = 120 s (2 minutos transcurridos)
  • t = 180 s (3 minutos transcurridos)

Paso 3: Convierte a currentPower: basePower × endurancePercent ÷ 100
donde basePower = SPEED × 100 ÷ 20
Idea clave
Speed controla qué tan rápido. Endurance controla por cuánto tiempo. Todo bot comienza al 100% de potencia — tu Speed define la velocidad máxima, tu Endurance define qué tan rápido se drena.

La estructura del código

Tres bloques trabajan juntos. Defines tus stats en on start, usas el Botón B para elegir el momento del partido que quieres probar, luego presionas el Botón A para manejar 2 segundos a ese nivel de potencia.

on start — define tus stats
set SPEED to 0   // ← cambia al valor de tu stat card
set ENDURANCE to 0   // ← cambia al valor de tu stat card
set TEST_DURATION_MS to 2000   // ráfaga de 2 segundos
set simulatedMatchTime to 0   // empieza al inicio del partido. No hay que cambiar esto
computeStats — la fórmula se ejecuta aquí
set basePower to SPEED × 100 ÷ 20   // velocidad máxima de ruedas
set DECAY_RATE to 20 − ENDURANCE
set endurancePercent to 100 − DECAY_RATE × simulatedMatchTime ÷ 40
set endurancePercent to max of endurancePercent and 20   // mínimo del 20%
set currentPower to round(basePower × endurancePercent ÷ 100)
on button A — ejecutar ráfaga de 2 segundos
call computeStats   // calcula la potencia para el simulatedMatchTime actual
set left/right wheel speed to currentPower %
while running and elapsed < TEST_DURATION_MS:
  // revisar borde — manejar si se detecta
  pause BORDER_CHECK_MS
stop all wheels  →  show string "LISTO"
on button B — ciclar el tiempo de partido simulado
if simulatedMatchTime = 0:  set to 60   // LED: 1 columna
else if simulatedMatchTime = 60:  set to 120   // LED: 2 columnas
else if simulatedMatchTime = 120:  set to 180   // LED: 3 columnas
else:  set to 0   // LED: punto central
simulatedMatchTime es la variable clave. Alimenta computeStats, que recalcula cuánta potencia debería tener el bot en ese momento del partido. La cambias con B — no esperando que pase el tiempo.

📏 Cómo funciona la prueba

Haces cuatro ráfagas de 2 segundos — una para cada tiempo de partido simulado. Cada ráfaga parte desde la misma línea. Marcas con cinta dónde se detiene el bot. Mides los cuatro al final.

Ráfaga 1
t = 0 · Inicio
LED con punto central. Bot a plena potencia. Presiona A.
Ráfaga 2
t = 60 s · 1 min
LED con 1 columna. Presiona B una vez, luego A.
Ráfaga 3
t = 120 s · 2 min
LED con 2 columnas. Presiona B de nuevo, luego A.
Ráfaga 4
t = 180 s · 3 min
LED con 3 columnas. Presiona B de nuevo, luego A.
📏 Cómo medir
  1. Coloca un trozo de cinta en el suelo — esta es la línea de salida. Se queda ahí para los cuatro intentos.
  2. Después de cada carrera de 2 segundos, coloca un trozo de cinta en la parte delantera del bot para marcar dónde se detuvo.
  3. Regresa el bot a la línea de salida antes de cada nueva carrera.
  4. Después de los cuatro intentos, mide desde la cinta de salida hasta cada marca. Registra en centímetros (cm).
▶ Corre la prueba — paso a paso
  1. 1
    Coloca un trozo de cinta en el suelo. Esta es la línea de salida para los cuatro intentos.
  2. 2
    Coloca el bot en la línea de salida. Revisa el LED — debe mostrar el punto central (t = 0). Si muestra columnas, presiona B hasta volver al punto central.
  3. 3
    Presiona A. El bot maneja 2 segundos y se detiene. Coloca un trozo de cinta en la parte delantera del bot para marcar dónde se detuvo. Esta es tu marca de Ráfaga 1.
  4. 4
    Regresa el bot a la línea de salida.
  5. 5
    Presiona B. El LED muestra 1 columna — el bot ahora simula t = 60 segundos (1 minuto dentro del partido).
  6. 6
    Presiona A. Marca dónde se detiene el bot. Esta es tu marca de Ráfaga 2.
  7. 7
    Regresa el bot al inicio. Presiona B → el LED muestra 2 columnas (t = 120 s, 2 min). Presiona A. Marca dónde se detiene — Ráfaga 3.
  8. 8
    Regresa el bot al inicio. Presiona B → el LED muestra 3 columnas (t = 180 s, 3 min). Presiona A. Marca dónde se detiene — Ráfaga 4.
  9. 9
    Mide desde la cinta de salida hasta cada una de las cuatro marcas. Registra todas las distancias en centímetros.
Paro de emergencia: Presiona A + B juntos en cualquier momento. El bot se detiene de inmediato y muestra una X en el LED.

La oración de la diferencia
Predicción + observación + diferencia = un enunciado científico completo. La fórmula predice una máquina perfecta. Tu bot no es una máquina perfecta. Nombra una causa del mundo real de tu diferencia — así es como mejoran los modelos.
Cuidado — Errores comunes
Presionaste B demasiadas veces
B cicla 0 → 60 → 120 → 180 → 0. Revisa el patrón de LEDs antes de presionar A. Si estás en el tiempo incorrecto, sigue presionando B hasta ciclar de vuelta.
SPEED o ENDURANCE siguen en 0
Si el bot no se mueve, revisa on start. Ambos valores son 0 por defecto en el programa base — debes escribir los tuyos.
Mediste antes de que el bot se detuviera completamente
Espera a que aparezca "LISTO" en la pantalla LED antes de colocar tu marca de cinta. El bot se detiene automáticamente a los 2 segundos.
El bot chocó con el borde y giró antes de detenerse
El código de detección de borde girará el bot alejándolo del borde. Si esto ocurre, la distancia no es en línea recta. Repite esa ráfaga con el bot alejado de cualquier borde.
