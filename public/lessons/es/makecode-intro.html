Introducción a MakeCode

MakeCode es donde escribes el código que controla tu robot. Encajas bloques como piezas de rompecabezas — no se requiere escribir. Esta guía te explica todo.

Cutebot Pro Bloques JavaScript micro:bit v2
Sección 1
¿Qué es MakeCode?

MakeCode es un sitio web gratuito que te permite programar tu micro:bit. Lo abres en cualquier navegador — sin instalar nada. Todo lo que construyes ahí se carga en el micro:bit, que va dentro de tu Cutebot Pro y le dice qué hacer.

Ábrelo en: makecode.microbit.org

Funciona en Chrome, Edge, Firefox y Safari. No necesitas cuenta para empezar, pero si quieres guardar tu trabajo en la nube, sí la necesitas.

Sección 2
¿Qué son los bloques?

Los bloques son instrucciones. Cada bloque hace una sola cosa — mover un motor, mostrar un número, esperar un segundo. Encajas bloques para construir una secuencia. El programa corre de arriba a abajo, un bloque a la vez.

Piénsalo como encajar piezas. Cada pieza encaja en la siguiente. La forma de un bloque te dice dónde puede conectarse — igual que las piezas de LEGO solo encajan en ciertos lugares.
Tu primer bloque — al iniciar
Cargando bloques…
basic.showString("Hello!")
Este bloque corre una sola vez, en el momento en que el micro:bit enciende. Hace desfilar la palabra "Hello!" por la cuadrícula de LEDs.

Pruébalo en el simulador — verás las letras desfilar por la pantalla pequeña de la izquierda.
Formas de los bloques

La forma de un bloque te indica qué hace y dónde encaja. No necesitas memorizar esto — las reconocerás de forma natural después de unos minutos construyendo.

Bloques de evento — "cuando esto ocurra"
Siempre van en la parte superior de una pila. Esperan que algo ocurra — como que el micro:bit encienda, o que presiones un botón — y luego ejecutan los bloques de adentro.
al presionar botón A
Bloques de acción — "haz esto"
Son los bloques de acción. Encajan dentro de un bloque de evento y corren en orden, de arriba a abajo.
mostrar texto "¡Go!"
Bloques de valor — "un número o palabra"
Encajan en huecos redondos u ovalados dentro de otros bloques. Llevan un valor — como un número de velocidad o una lectura de sensor. Su color corresponde a su categoría.
SPEED
Bloques booleanos — "verdadero o falso"
Son condiciones — preguntas que solo pueden ser verdaderas o falsas. Encajan en las ranuras hexagonales dentro de los bloques de Lógica como "si/entonces." Los bloques de Lógica son color turquesa.
¿botón A presionado?
Sección 3
Categorías de bloques — los colores significan algo

Cada categoría tiene un color. Una vez que conoces los colores, puedes encontrar cualquier bloque en segundos. Estas son las que más usarás.

Básico Muestra texto, números y patrones en los LEDs. Pausa y limpia la pantalla.
Entrada Reacciona a los botones A, B, A+B y al acelerómetro (sensor de inclinación).
Bucles Repite un bloque un número fijo de veces, o en bucle para siempre.
Lógica Decisiones si/entonces/sino. "Si el sensor detecta el borde, detente."
Variables Crea cajas con nombre que guardan números. SPEED, POWER, TURNING.
Matemáticas Suma, resta, multiplica, divide. También módulo, valor absoluto y números aleatorios.
Cutebot Pro Controla motores, lee sensores y maneja las luces. Los bloques específicos del robot.
LED Enciende o apaga LEDs individuales. Dibuja gráficas de barras y animaciones.
¿No encuentras un bloque? Haz clic en la categoría donde crees que está. Si no lo ves, desplázate hacia abajo — la mayoría de las categorías tienen más bloques ocultos. También puedes escribir en la barra de búsqueda en la parte superior del panel de herramientas.
Sección 4
Construye tu primer programa — paso a paso

Vamos a construir un programa que muestra un corazón cuando presionas el botón A, y un número cuando presionas el botón B. Usa tres categorías: Entrada, Básico y LED.

1
Abre MakeCode e inicia un nuevo proyecto

Ve a makecode.microbit.org → haz clic en Nuevo Proyecto → ponle un nombre como mi-primer-programa.

2
Busca el bloque "al presionar botón A"

Haz clic en la categoría Entrada en el panel de herramientas. Arrastra "al presionar botón A" al área de trabajo.

3
Coloca un bloque "mostrar ícono" dentro

Haz clic en Básico. Arrastra "mostrar ícono" y encájalo dentro del bloque de botón. Elige el corazón ❤️.

4
Repite para el botón B — muestra un número

Arrastra otro bloque "al presionar botón". Cambia el menú desplegable de A a B. Coloca un bloque "mostrar número" dentro y escribe 42.

5
Pruébalo en el simulador

Haz clic en el botón A del simulador (abajo a la izquierda del micro:bit virtual). Deberías ver el corazón. Haz clic en B — deberías ver el 42 desfilar.

Así se ve tu programa terminado
Cargando bloques…
input.onButtonPressed(Button.A, function () {
    basic.showIcon(IconNames.Heart)
})
input.onButtonPressed(Button.B, function () {
    basic.showNumber(42)
})
Dos pilas separadas — una para cada botón. Ninguna corre hasta que presionas el botón.

Botón A → corazón en pantalla.
Botón B → el número 42 desfila.

El micro:bit vigila ambos botones al mismo tiempo. El que presiones primero corre primero.
Acabas de escribir un programa real. Tiene dos manejadores de eventos — código que espera a que algo ocurra. Ese mismo patrón se usa en cada programa de partido de Velocity Arena.
Sección 5
Variables — cajas con nombre para números

Una variable es un lugar con nombre en la memoria que guarda un valor. Cada programa de Velocity Arena usa variables para almacenar tus estadísticas: SPEED, ENDURANCE, TURNING, POWER. Así se ven en bloques.

Crear y usar una variable
Cargando bloques…
let SPEED = 8
let POWER = 6
basic.showNumber(SPEED)
basic.pause(1000)
basic.showNumber(POWER)
Asignar variable — le da un valor a la caja. Haz esto al inicio.

Usar variable — pone el valor dentro de otro bloque. Donde uses SPEED, el micro:bit lo reemplaza por 8.

Para crear una variable: haz clic en Variables → Crear una Variable → escribe el nombre.
Tus cuatro estadísticas deben sumar 20. SPEED + ENDURANCE + TURNING + POWER = 20. Fija los números al inicio de tu programa antes de agregar cualquier otra cosa.
Sección 6
Si / sino — tomando decisiones

Los programas necesitan tomar decisiones. "Si el sensor de borde se activa, retrocede. De lo contrario, sigue avanzando." Eso es un bloque si/sino. Verifica una condición y ejecuta código diferente según la respuesta.

Ejemplo de si/sino
Cargando bloques…
let score = 0
if (score > 5) {
    basic.showIcon(IconNames.Happy)
} else {
    basic.showIcon(IconNames.Sad)
}
La forma de diamante es la condición — la pregunta de sí o no.

Si el puntaje es mayor que 5 → cara feliz.
Sino → cara triste.

Intenta cambiar score a 3 y observa cómo el simulador cambia a la cara triste.
Sección 7
Bloques Cutebot Pro — cómo manejar el robot

Los bloques de Cutebot Pro no aparecerán hasta que agregues la extensión. Haz esto una vez por proyecto. Después, una categoría rosa "Cutebot Pro" aparece en tu panel de herramientas.

1
Abre Extensiones

Desplázate hasta el final del panel de herramientas y haz clic en Extensiones.

2
Busca Cutebot

Escribe cutebot pro en el cuadro de búsqueda y presiona Enter.

3
Haz clic en el recuadro de Cutebot Pro

MakeCode descarga la extensión. Una categoría rosa de Cutebot Pro aparece en tu panel de herramientas. Listo.

Manejar en línea recta con Cutebot Pro
Cargando bloques…
let SPEED = 8
let currentPower = 0
input.onButtonPressed(Button.A, function () {
    currentPower = SPEED * 100 / 20
    CutebotPro.pwmCruiseControl(currentPower, currentPower)
    basic.pause(2000)
    CutebotPro.stopImmediately(CutebotProMotors.ALL)
})
pwmCruiseControl(izquierda, derecha) — envía potencia a ambos motores. El mismo número en ambos lados = línea recta.

pause(2000) — espera 2 segundos (2000 milisegundos).

stopImmediately — corta ambos motores al instante.

Este es el mismo patrón que el programa de Prueba de SPEED.
currentPower = SPEED × 100 ÷ 20 — esto convierte tu estadística (1–20) en un porcentaje de potencia del motor (5%–100%). SPEED 10 = 50% de potencia. SPEED 20 = 100% de potencia.
Sección 8
Descargar al micro:bit

Probar en el simulador es útil, pero la prueba real es en el robot. Así envías tu programa al micro:bit.

Paso 1
Conecta el micro:bit
Usa el cable USB. Una unidad llamada MICROBIT aparece en tu computadora.
Paso 2
Haz clic en Descargar
El botón grande morado/azul en la parte inferior de MakeCode. La app envía tu programa directamente al micro:bit.
Paso 3
Vincular
Aparece una solicitud de vinculación. Sigue los pasos para conectar el micro:bit. Solo necesitas hacerlo una vez por dispositivo.
Paso 4
Desconectar
La luz amarilla parpadea mientras carga. Cuando se detiene, desconecta el cable y coloca el micro:bit en el robot.
La luz amarilla parpadeando = no desconectes. Espera a que se detenga. Jalar el cable mientras está escribiendo puede corromper el programa.
Después de vincular una vez, la siguiente descarga es instantánea. La app recuerda tu micro:bit. Solo conéctalo, haz clic en Descargar y parpadea automáticamente cada vez.

Sección 10
JavaScript — qué es y cuándo usarlo

Cada bloque es secretamente JavaScript. Cuando cambias al modo JavaScript en MakeCode, ves el código exacto que representan tus bloques. Es el mismo programa — solo escrito como texto en vez de imágenes.

Modo Bloques → el mismo programa → Modo JavaScript
Bloques
Cargando bloques…
input.onButtonPressed(Button.A, function () {
    basic.showString("Go!")
    basic.pause(500)
    basic.clearScreen()
})
JavaScript
input.onButtonPressed(Button.A, function () { basic.showString("Go!") basic.pause(500) basic.clearScreen() })

Los dos hacen exactamente lo mismo. La versión con bloques es más fácil de leer. La versión en JavaScript es más rápida de escribir una vez que sabes lo que haces — y es así como se escribe el software profesional.

Cómo cambiar entre modos
→
Bloques → JavaScript

Haz clic en el botón { } JavaScript en la parte superior de MakeCode. Tus bloques se convierten al instante en código que puedes leer y editar.

←
JavaScript → Bloques

Haz clic en 🧩 Bloques. MakeCode convierte tu código de vuelta a bloques. Si tu código tiene un error tipográfico, te avisará primero.

Una regla importante: no todo programa en JavaScript puede convertirse de vuelta a bloques. Si escribes cosas en JavaScript que no tienen un bloque equivalente, MakeCode marcará esas líneas como "no traducibles." Está bien — solo significa que estás escribiendo código que va más allá de lo que los bloques pueden mostrar.
Consejos para leer JavaScript
function () { }
Un contenedor para un grupo de bloques. Todo lo que está entre las { } llaves corre junto.
let x = 0
Crea una variable llamada x y la establece en 0. Igual que el bloque "asignar variable".
basic.pause(1000)
Espera 1000 milisegundos = 1 segundo. El número entre paréntesis es la entrada.
// comentario
Todo lo que sigue a // es una nota para humanos. El micro:bit lo ignora. Muy útil para explicar qué hace una línea.
if ( ) { } else { }
Un bloque de decisión en forma de texto. La condición va en los ( ) paréntesis. La acción va en las { } llaves.
while ( ) { }
Sigue ejecutando el código dentro de { } mientras la condición en ( ) sea verdadera. Se usa en cada bucle de partido de Velocity Arena.
Patrón de Velocity Arena — lee esto en JavaScript
// Fija tus estadísticas aquí. Deben sumar 20. let SPEED = 8 let ENDURANCE = 6 let TURNING = 3 let POWER = 3 // Presiona A para manejar 2 segundos input.onButtonPressed(Button.A, function () { let power = SPEED * 100 / 20 CutebotPro.pwmCruiseControl(power, power) basic.pause(2000) CutebotPro.stopImmediately(CutebotProMotors.ALL) })
Este es el programa de Prueba de SPEED en JavaScript.

Líneas 2–5: cuatro variables que suman 20.
Línea 8: manejador del botón A.
Línea 9: calcula la potencia del motor desde SPEED.
Línea 10: hace girar ambos motores.
Línea 11: espera 2 segundos.
Línea 12: detiene.

Puedes pegar esto en MakeCode y cambiar a la vista de Bloques para verlo como bloques.
