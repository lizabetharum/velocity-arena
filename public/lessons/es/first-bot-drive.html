on button A pressed — Ejecutar un manejo cronometrado
Cargando bloques…
let SPEED = 1
let TEST_DURATION_MS = 3000
let currentPower = 0
let running = false
let testStart = 0
input.onButtonPressed(Button.A, function () {
    currentPower = SPEED * 100 / 20
    basic.showNumber(SPEED)
    basic.pause(800)
    basic.plotBarGraph(currentPower, 100)
    basic.pause(800)
    basic.clearScreen()
    basic.pause(500)
    running = true
    testStart = input.runningTime()
    CutebotPro.motorRun(CutebotProMotors.ALL, CutebotProDir.Forward, currentPower)
    while (running && input.runningTime() - testStart < TEST_DURATION_MS) {
        CutebotPro.motorRun(CutebotProMotors.ALL, CutebotProDir.Forward, currentPower)
    }
    CutebotPro.stopImmediately(CutebotProMotors.ALL)
    running = false
    basic.showLeds(`
        # . . . #
        . # . # .
        . . # . .
        . # . # .
        # . . . #
        `)
    basic.pause(500)
    basic.clearScreen()
})
Fórmula. SPEED × 5 convierte tu stat en % de potencia del motor.
Mostrar y previsualizar. Ves el número de SPEED desplazarse, luego una barra de potencia antes de que el bot se mueva.
Bucle while. Mantiene los motores funcionando hasta que pasa TEST_DURATION_MS (3000ms). A+B lo interrumpe antes.
Parar + X. Corta la potencia y muestra X. Esa X es tu señal para medir.
on button B pressed — Cambiar la velocidad sin recargar el programa
Cargando bloques…
let SPEED = 1
input.onButtonPressed(Button.B, function () {
    if (SPEED >= 20) {
        SPEED = 1
    } else {
        SPEED += 1
    }
    basic.showNumber(SPEED)
    basic.clearScreen()
})
Ciclo con reinicio. Suma 1 cada vez que se presiona. Al llegar a 20, vuelve a 1 — nunca sale del rango.
Confirma la nueva velocidad. El número se desplaza en el LED antes de que presiones A.
Sin recargar el programa. Prueba tus 3 velocidades en una sola sesión.

Qué hace cada bloque
on start
Basic (azul). Se ejecuta una vez cuando el micro:bit se enciende. Coloca aquí tus valores iniciales — SPEED y motorPower se configuran antes de presionar cualquier botón.
on button A pressed
Input (magenta). Todo lo de adentro se ejecuta cuando alguien presiona el botón A. Este es tu botón IR — inicia la secuencia de manejo.
set SPEED to 6
Variables (rojo). Crea una caja llamada SPEED y pone 6 dentro. Cámbialo a 12 para la Carrera 2 — es lo único que cambias entre carreras.
set motorPower to SPEED×100÷20
Variables (rojo). Tu fórmula en forma de bloque. El micro:bit calcula SPEED×100÷20 y guarda el resultado. SPEED=6 → 30. SPEED=12 → 60.
show string "Go"
Basic (azul). Desplaza la palabra "Go" en la pantalla LED del micro:bit — una señal visual de que el bot está a punto de moverse.
set left wheel speed motorPower %,
right wheel speed motorPower %
Cutebot Pro (verde). Gira ambas ruedas al motorPower %. Así es como el bot avanza — pones cada rueda al mismo valor para que vaya recto.
pause (ms) 5000
Basic (azul). Espera 5.000 milisegundos = 5 segundos. Las ruedas siguen girando durante esta pausa. Después de 5 segundos corre el siguiente bloque.
set all wheel to stop immediately
Cutebot Pro (verde). Corta la potencia a ambas ruedas de inmediato. Sin esto el bot seguiría rodando después de la pausa.
on button B pressed
Input (magenta). Paro de emergencia. Si algo sale mal, presiona B. Detiene todas las ruedas y muestra una X en el LED.

Cómo funciona el código
// ── on start — se ejecuta una vez al encender el micro:bit ──
on start:
  set SPEED = 6                    // ← cámbialo a 12 para la Carrera 2
  set motorPower = SPEED × 100 ÷ 20  // = 30% para Carrera 1
// ── Botón A — IR ─────────────────────────────────
on button A pressed:
  show string "Go"
  clear screen
  set left wheel motorPower%, right wheel motorPower%
  pause (5000 ms)           // las ruedas giran por 5 segundos
  stop all wheels
// ── Botón B — PARO DE EMERGENCIA ─────────────────
on button B pressed:
  stop all wheels
  show leds  // patrón en X
  pause (3000 ms)
  clear screen

Entre carreras, solo cambias una cosa: SPEED = 6 para la Carrera 1 → SPEED = 12 para la Carrera 2. Descarga de nuevo después de cambiarlo.

La gran pregunta

Cuando duplicaste Speed (6 → 12), ¿también se duplicó la distancia?

Exactamente correcto. Una razón limpia de 2× confirma la relación lineal. En Velocity Arena puedes predecir la distancia desde los puntos de Speed sin adivinar — la fórmula funciona.
Revisa de nuevo. Speed se duplicó (6 → 12) y la potencia del motor se duplicó (30% → 60%), así que la distancia también debería duplicarse aproximadamente. Revisa tu razón en la Sección 3. Si está entre 1,8 y 2,2, la fórmula sigue siendo válida — los bots reales tienen pequeñas variaciones.
Buena observación. La fórmula predice un 2× perfecto, pero los robots reales tienen fricción, diferencias de batería y variaciones de tiempo. Una razón entre 1,8× y 2,2× confirma la relación lineal. La pequeña diferencia respecto a 2,0 es normal.

💡 Pista para la pregunta 3
Usa la fórmula: motorPower = Speed × 100 ÷ 20.
Speed 12 → 12 × 100 ÷ 20 = 60%.
Speed 16 → 16 × 100 ÷ 20 = 80%.
Eso es 20% más de potencia. Como la relación es lineal, espera aproximadamente un 20% más de distancia también.
