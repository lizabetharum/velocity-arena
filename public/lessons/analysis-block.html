Write Your Sentence
Must name an INPUT variable — not a result. "We lost to fast teams" = result. "Turning is missing from our equation" = input.
My model consistently because it .
That looks like an outcome, not an input variable. Examples of input variables: Speed, Turning, Power, Endurance, distance, launch angle. Do not write: lost, won, goals, score, opponent, match.
Most Common Error

What you might write: "We lost to fast teams." — That is a result.

What you need: "Our equation uses only Speed, but high-Turning opponents scored from angles our bot didn't cover — Turning is missing from the model."
