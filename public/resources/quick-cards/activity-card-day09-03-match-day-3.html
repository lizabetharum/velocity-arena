MATH: Gap % = |prediction − actual| ÷ prediction × 100 | Identify input variable when gap >20%
Before You Start
  • Formula Relay board from this morning posted and visible
  • Match data logs on tables with Round 1 predictions pre-filled
  • Round-robin bracket for Day 3 posted where all teams can see
  • Data dashboard and interactive tool loaded and tested
  • Work out the gap formula: predicted 5, scored 3 = 40%
  • Students must trace prediction errors to input variables, not outcomes.
Students Produce
  • Three match predictions using Formula Relay target type
  • Post-match data entries (goals, W/L) for all three rounds
  • One variable sentence per match where gap >20%
  • Sentence connection to next round's prediction
  • Complete data dashboard entry before transition
Reference
FORMULA TYPES: Endurance P(t)=100−kt | Distance | Linear y=mx+b | Percent Change
LOSS RECOVERY: (1) 30-sec pause. (2) Check input variable. (3) Name variable to change. (4) State sentence aloud.

Say This
Open
Three matches. Prediction written before, results after, loss recovery if you lose. One new thing: if the gap is more than 20%, write one sentence: The variable my model missed was _____ because _____.
Loss Recovery Step 1
That result was frustrating. That makes sense.
Loss Recovery Step 2
Your prediction used [formula]. You predicted [X] goals and scored [Y]. Look at one input: did the number match what you actually ran?
Stuck on Gap
Tell me prediction and actual. Which input—stat, coefficient, starting value—did not match? Start there.
Not This
Do not accept 'fewer goals' or 'slow bot' or blank Notes for >20% gaps. Push to the input number.
Watch For → Redirect
Gap entry blank for >20% gapStop at table. 'What variable did the model miss? Notes column, that row.'
Volatile gap from low predictionName it: 'Your prediction was low. What assumption did your formula make?'
Outcome instead of input'Which number did you plug in? What would it need to be?' [Pause 7 sec.]
Change formula before Round 2'Not today. Use the target type once. After Round 2, Round 3 is your call.'
Mechanical observation not stat'Slow connects to which stat? What value? What does today suggest?'
Dashboard incompleteHold transition. Verify all three match results per team.
