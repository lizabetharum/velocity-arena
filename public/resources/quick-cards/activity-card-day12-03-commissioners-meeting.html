Commissioner's Meeting + Vote

Day 12 · Match-Build-Make · 90 min
Follows Lunch / Snack Break
MATH: Percent Change: (new − old) / old × 100. Disproportionate Impact: objecting team's change ≥ 10 pp above median.
Before You Start
  • Work through both practice problems; verify constraint satisfaction.
  • Set presentation order — mid-confidence team first, strongest team NOT first.
  • Clear wall section, load markers, print Vote Record and Season 2 sheets.
  • Distribute Math Verification Sheet to every team before presentations.
  • Confirm data dashboards accessible on every device.
  • *Percent change precision matters for Season 2.*
Students Produce
  • 3-minute presentation with two data points and percent-change argument
  • Math Verification Sheet for every other team's proposal
  • Revised allocation satisfying all rules, sum = 20 (or 22 for Underdog)
  • Exit Ticket Q1: percent-change calculation with work shown
  • Exit Ticket Q2: valid allocation demonstrating constraint satisfaction
Reference
VOTING: Simple majority of non-proposing teams. DISPROPORTIONATE IMPACT: objecting team's percent change ≥ 10 pp above median. IMPOSSIBLE CONSTRAINT: Re-vote before writing. TOTALS: 20 points (all except Underdog), 22 points (Underdog).
Timing
0:00Launch11 days of data become permanent rules. Each team states rule + one data point.
0:02Voting Procedure3-min presentations, proposing team doesn't vote, majority of others passes, math verification required.
0:10Presentations: Time + Verify + VoteSignal at 2:30, call time at 3:00. Math check and non-proposing votes. If passed: write rule, 2-min objection window.
~1:00Connecting Question'Which stat most constrained if both rules pass?' If same: 'Does every team have valid allocation?'
~1:00Rule ConsolidationRead every passed rule aloud. Revise to satisfy every rule. Total = 20 (or 22 Underdog).
1:05Allocation Revision (18–25 min)Circulate with prompts. IF conflict: 'Show me. Which breaks first?'
1:25Exit Ticket (5 min) — NON-OPTIONALQ1: Percent change calculation. Q2: Valid allocation satisfying all rules. Skim Q1 for method error.
Say This
Open
Each team presents 3 minutes, cites two data points. Room checks math before vote. Proposing team does not vote. Rule passes if majority of other teams vote yes. Mathematical objections only: name the number and calculation.
Math Verify
Does this proposal use the data correctly? Can anyone verify the math?
Objection
Mathematical objection window open. State team name, specific number, and calculation in 2 minutes.
Hard Stop
Time. Is this the same proposal verified? If numbers changed, math check applies.
Not This
Do not acknowledge objections without a number. Do not vote before non-proposing team responds. Do not let proposing team vote.
Watch For → Redirect
Team goes past 3:00Call 'Time' without apology.
Different rule than verified'Is this the same proposal?' If numbers changed, recalculate before vote.
Vote before math check'Can anyone verify the math?' Do not vote until one team responds.
Objection without calculation'Name the number and calculation.' Window closes in 30 sec without it.
Two rules create impossible constraint'Can everyone build valid allocation?' If not, emergency re-vote.
Disengagement after first presentationRedirect to math before emotion spreads.
Hard Stop Exit Ticket is non-optional. Collect both questions. Skim Q1 for percent-change method vs. absolute-change error.
