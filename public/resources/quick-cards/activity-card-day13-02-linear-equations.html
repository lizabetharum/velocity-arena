MATH: Linear equation from two points: slope = (y₂ − y₁) / (x₂ − x₁); residual = predicted − actual
Before You Start
  • Post class data table on board and each worksheet
  • Check stat spread and identify low-variation columns
  • Prepare HTML page and three-bot worksheet per team
  • *Residual is prediction error, not failure.*
Students Produce
  • Linear equation from two selected bots
  • Bot C residual calculation with sign interpretation
  • Season 2 prediction with qualifying language
  • Match Gate whiteboard prediction
Reference
**Residual = Predicted − Actual** | Positive: over-predicted | Negative: under-predicted
**Build vs. Test:** Bots A & B set the line; Bot C is independent.
**Prediction Language:** 'Based on Season 1 class data, predicts approximately ___% win rate.'
Timing
0:00–0:05LaunchExplain data table. Build Bots A & B set line; Bot C is independent. Hard Stop: scan stat column—does it vary? If spread <2 points, redirect.
0:05–0:30Explore: BuildCirculate with checklist. Catch: wrong stat column, Build Bots too close, Test Bot C already used.
0:30–0:40Explore: TestCatch circular testing, residual sign confusion, and prediction language. Use prompts Q1–Q4.
0:40–0:48SummaryShare-outs: (1) slope meaning, (2) largest residual, (3) Season 2 prediction with 'approximately.'
0:48–0:50Match GateEvery team writes prediction with qualifying language. No sentence = no matches.
Say This
Open
The data is every team's stat value and Season 1 win percentage. You are analyzing a pattern across the class—which stats predict winning?
Hard Stop
Before choosing bots: does your stat column vary, or do bots cluster? If most bots are within 1–2 points, choose a different stat.
Key Prompt
Say 'predicts approximately' not 'will win.' Predictions are estimates, not guarantees.
Residual
Predicted minus actual. Positive = over-predicted. Negative = under-predicted.
Not This
Do not accept predictions without 'approximately' or 'based on class data.'
Watch For → Redirect
Team uses Bot A or B as Test Bot CThose bots are in your equation already. Choose a new bot.
Build Bots identical; slope near 0Find bots farther apart or choose a stat with more spread.
Residual sign confusionPredicted minus actual. If positive, over-predicted. If negative, under-predicted.
Large residual (>20 pts)That is real prediction error. What might your model be missing?
Prediction without qualifying languageAdd 'approximately.' Predictions are estimates, not guarantees.
Team: 'Equation proves [stat] causes winning'Does it prove causation, or describe a pattern in this class's data?
Hard Stop At 0:05: Scan the chosen stat column for variation. If bots cluster within 1–2 points, redirect: 'That stat lacks variation. Choose a different column.' Do not let teams build meaningless slopes.
