4 of 4
Day 12 · Open Lab / Mini-Consolidation · 35 min
Follows Commissioner's Meeting
MATH: Verify loadout meets all Commissioner rules simultaneously and sums to 20; system of inequalities consistency check
Before You Start
  • Load today's Commissioner rule in the What-If tool and test a sample loadout to see green boxes
  • Add up the smallest value each rule allows; if total exceeds 20, flag rule conflict
  • Post the three steps (Verify, Program, Test Drive) where all can see them
  • Fill in team names on the monitoring chart and rename Rule 1/2/3 to actual rules
  • Ensure MakeCode is open on devices, bots are charged, and data logs are ready
  • *The What-If tool prevents the most common mistake: fixing one rule then breaking it while fixing the next.*
Students Produce
  • Green-checked loadout in the What-If tool with every rule met and total = 20
  • Verified stats programmed into MakeCode and loaded to the bot
  • One test-drive data log line confirming bot movement matches the math
  • Exit ticket with hardest rule as an inequality and YES/NO confirmation of compliance
Reference
STEP 1 · Verify: Every rule green, total 20, no blanks.
STEP 2 · Program: Enter verified stats in MakeCode. Save and load.
STEP 3 · Test Drive: One run. Does bot match your math? Write one line.
Timing
0:00Launch & count rulesName the Commissioner's Meeting and point to the three steps. Have teams count rules they must meet. Listen for understanding.
0:01Step 1: Verify in What-If toolCirculate asking 'Is every box green and total 20?' Watch for rule conflicts and teams chasing best stats instead of meeting rules. Gate: no Step 2 until all boxes green, total 20, no blanks.
0:15Step 2: Program MakeCodeAsk 'Is every number from the tool in MakeCode right now?' Confirm code is saved and loaded. One student codes while others watch. Split the job: reader, typist, checker.
0:25Step 3: Test drive & logOne run per team. Ask 'What should look different from Season 1?' Pause 7 sec, then 'Write one line: what did you see, does it match your math?' Data goes to ENDS journal.
0:32Mini-share & exit ticketPick one team with interesting trade-off. Ask which rule forced a change. Name the math: 'Checking all rules at once is a system consistency check, like solving inequalities.' Collect exit tickets.
Say This
Open
You have 35 minutes. Three steps, in order, on the board. Verify your loadout in the What-If tool. Program it into MakeCode. Run one test drive. No one leaves until all three are done. Go.
Rule Conflict
Add up the smallest value each rule allows. If it is over 20, the rules conflict. Everyone check all rules at once in the tool.
Predict Before Run
What should look different from Season 1? [Pause 7 sec.] Write one line. What did you see? Does it match your math?
Lost Vote
You are working under rules you did not vote for. Season 2 data will show whether the rule limits you as much as you think. Back to the steps.
Not This
Do not ask how teams feel about the vote. Do not reopen the vote. Do not fix code if bot does not match prediction.
Watch For → Redirect
Rules cannot all be met at onceAsk teams to add up the smallest value each rule allows. If total exceeds 20, stop and fix with the whole class before Season 2 starts.
Team chasing best stats instead of meeting ruleAsk 'Does your loadout meet the rule, yes or no?' If yes, it is valid. Do not discuss strategy now.
Team tries to program before Step 1 is done'Is every box green in the tool? Check that first. Program verified numbers, not draft ones.'
One student codes while others watch passivelySplit the job: 'Who is reading values out loud? One reads from tool, one types, one checks against wall rules.'
Bot behavior does not match prediction'Write down what you saw. That is your first Season 2 data point.' Data goes to ENDS journal tomorrow.
Team skips test drive because code looks correct'Right numbers in MakeCode and a bot that moves as expected are two different things. One run. Write the line.'
Hard Stop EXIT TICKET REQUIRED. Write: (1) hardest rule as an inequality and why; (2) YES/NO circle and which rule fails if no. Teams unable to write a rule as an inequality have a gap before Season 2.
