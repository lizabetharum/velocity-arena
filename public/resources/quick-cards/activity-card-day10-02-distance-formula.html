MATH: Distance Formula: d = √[(x₂−x₁)² + (y₂−y₁)²] | Efficiency = Progress ÷ Total Movement
Before You Start
  • Work through revised worksheet using Position B (6, 3). Calculate A→G, A→B, B→G.
  • Test case where B→G > A→G. Be ready to explain why.
  • Write distance formula on board: A = (4, 2), G = (8, 2).
  • Prepare monitoring chart for teams using full formula vs. estimate-check.
  • *Save algebraic WHY for Summary Strategy 1.*
Students Produce
  • Three distance calculations with all steps shown.
  • Estimate-before-calculate check for B→G.
  • Efficiency ratio and minimum kicks.
  • Exit ticket: one calculation and one interpretation.
Reference
**Algebra**: Distance formula from Pythagorean theorem. When y = 2, y-term cancels.
**Efficiency**: Ratio near 1 = useful movement. Near 0 = ball moved but distance unchanged.
**Counter-Intuitive**: B→G can exceed A→G. This is correct math.
