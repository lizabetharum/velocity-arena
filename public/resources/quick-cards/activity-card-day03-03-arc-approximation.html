Arc Approximation: Introducing TURNING
3 of 4
Day 3 · Match-Build-Make · 90 min
Follows Energy Reset
MATH: turnRatio = 0.2 + (TURNING × 0.02); Left wheel = motorPower × (1 − turnRatio); Right wheel = motorPower × (1 + turnRatio)
Before You Start
  • Solve turnRatio for T = 3, 7, 12 with motorPower = 50
  • Predict bot behavior at T = 10 vs. T = 2; write prediction before class
  • Read Teacher Content Note; identify one unsure concept
  • Set up floor grid with origin marked and axes labeled
  • *Arc approximation is piecewise linear. Higher TURNING ≠ automatic coverage—tight spirals concentrate in one zone.*
Students Produce
  • Distance calculations using d = √((x₂–x₁)² + (y₂–y₁)²)
  • Arc trace sheets for TURNING paths (T=2, 5, 10)
  • Coverage data: circled grid squares for each T value
  • TURNING stat allocation justified by trial data
Reference
STAT ALLOCATION: Speed + Endurance + TURNING ≤ 19
KEY MISCONCEPTION: T=10 spirals tightly (fewer squares); T=5 sweeps wider (more squares).
EXAMPLES:
T=2 → ratio=0.24 → L=38, R=62
T=5 → ratio=0.30 → L=35, R=65
T=10 → ratio=0.40 → L=30, R=70

Say This
Open
Your bot starts in a corner. The ball is at (4,2). Reach it before your opponent.
Key Moment
Point to the corner closest to the ball. Now use the formula to check.
Arc Approximation
A curved road is many short straight segments. Your robot does exactly this.
Discovery
Calculate T=5 using 0.2 + (5 × 0.02). Find turnRatio, then wheel speeds with motorPower = 50. You have 90 seconds.
Not This
Do NOT say 'higher TURNING always means more coverage.' Do NOT skip the exit ticket.
Watch For → Redirect
Teams drawing parallel lines instead of angled arcSay: 'After each segment, direction changes. Angle each segment slightly to build a curve.'
Team predicts T=10 covers most; data shows T=5 covers moreProbe: 'Why did the tight spiral cover fewer squares than T=5?'
Robot drifts or starts from different positionsTurn it into data moment: 'Real robots drift. Does that change your TURNING strategy?'
Student says 'turnRatio tells you degrees to turn'Clarify: 'turnRatio is a speed ratio. What two things does it compare?'
Team finishes earlyChallenge: 'Find a TURNING value for most uniform coverage.'
Team struggles to see curve formingSimplify to one-segment test first. Get them to see the curve before adding loop structure.
Hard Stop Exit Ticket is non-optional. If running behind, trim Bridge to Power or Results Share. Protect the exit ticket. Collect all slips before students leave.
