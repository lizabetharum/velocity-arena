Launch Sequence — the code

Your opening move goes corner → midline → ball: two turns and two drives. Paste it into STUDENT ZONE B of the match code and fill in four numbers — two turn angles and two drive times in milliseconds.

You fill in four numbers: your two turn angles and your two drive times (ms). Each ms comes from your Distance Lab equation. The locked part of the match code drives the last bit and kicks (strength = Power²).
  1. Open the match code in MakeCode and find ★ STUDENT ZONE B — LAUNCH SEQUENCE ★ (the // YOUR CODE HERE line).
  2. For each leg: measure the distance, then ms = (distance − start-up) ÷ speed × 1000 (your own equation).
  3. Set the turn angles with a protractor or start with 45° — no trig needed. Type the four moves in, filling your numbers into the ★ spots.
  4. Download, press A to set up, press A again to launch. Check the bot ends up behind the ball, facing the goal.
// ═══════════════════════════════════════════════
//   LAUNCH SEQUENCE — corner → midline → ball, then kick
//   Goes inside ★ STUDENT ZONE B ★ of the match code.
//   Fill in FOUR numbers: two angles and two times (ms).
// ═══════════════════════════════════════════════

// LEG 1 — turn toward the midline, then drive out to it
CutebotPro.trolleySteering(CutebotProTurn.LeftInPlace, 45)     // ★ LEG-1 ANGLE ★
basic.pause(300)
CutebotPro.pwmCruiseControl(motorPower, motorPower)
basic.pause(2800)                                        // ★ ms1 — corner to midline ★
CutebotPro.stopImmediately(CutebotProMotors.ALL); basic.pause(150)

// LEG 2 — turn to face the ball head-on, then drive to it
CutebotPro.trolleySteering(CutebotProTurn.RightInPlace, 45)    // ★ LEG-2 ANGLE ★
basic.pause(300)
CutebotPro.pwmCruiseControl(motorPower, motorPower)
basic.pause(1500)                                        // ★ ms2 — midline to ball ★
CutebotPro.stopImmediately(CutebotProMotors.ALL)
Milliseconds. basic.pause counts in ms, so multiply your seconds by 1000. Worked bot (speed 38, start-up −7): leg 1 = 100 cm → (100+7)÷38 = 2.8 s → 2800 ms; leg 2 = 50 cm → (50+7)÷38 = 1.5 s → 1500 ms. The kick strength is Power² automatically.
