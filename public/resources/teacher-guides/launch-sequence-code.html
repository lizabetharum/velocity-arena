Launch Sequence — the code

Aim your bot at the ball, then it drives the exact diagonal distance and kicks. You set one number — the drive time in milliseconds — download, aim, and press A.

You change exactly one line: let driveMs = …. Leave everything else alone. Your SPEED and POWER are the same stats as the Distance Lab — set once.
  1. Add the Cutebot Pro extension, switch to JavaScript, select all, delete, paste this in.
  2. Set SPEED and POWER to your team's stats (once).
  3. Each try: work out the diagonal distance to the ball, turn it into a drive time in ms, put it on the ★ line.
  4. Point the bot straight at the ball by hand, Download, press A. It drives to the ball and kicks.
// ═══════════════════════════════════════════════
//   LAUNCH SEQUENCE — drive to the ball, then kick
//   1. Aim the bot straight at the ball (by hand).
//   2. Put your diagonal drive time (ms) on the ★ line.
//   3. Download, press A. It drives, then kicks.
// ═══════════════════════════════════════════════

let SPEED = 5                     // your Speed stat (same as the Distance Lab). Set once.
let POWER = 5                     // your Power stat. Set once.
let motorPower  = SPEED * 100 / 20
let chargePower = Math.min(POWER * POWER, 100)

let driveMs = 2800                // ★ CHANGE ONLY THIS NUMBER ★  (diagonal drive time in ms)

basic.showString("A")

input.onButtonPressed(Button.A, function () {
    basic.showString("GO")
    // drive straight to the ball (you aimed it by hand)
    CutebotPro.pwmCruiseControl(motorPower, motorPower)
    basic.pause(driveMs)
    CutebotPro.stopImmediately(CutebotProMotors.ALL)
    basic.pause(150)
    // kick
    CutebotPro.pwmCruiseControl(chargePower, chargePower)
    basic.pause(400)
    CutebotPro.stopImmediately(CutebotProMotors.ALL)
    basic.showString("A")
})
Milliseconds again. basic.pause counts in ms, so 2.8 s = 2800 ms — multiply your seconds by 1000. The kick strength comes from POWER² automatically; you don't set it by hand.
