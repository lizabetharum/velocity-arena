10

Spreadsheets & Research Data

Every recall check, diagnostic, and interleaved problem set your students submit lands in a Google Sheet shared with you. That same data flows — anonymized — to the research team. Here's how it works.

Step 1 · Student
Student submits a worksheet
Their first name, last initial, team, and answers are written to your site's source sheet — one sheet per task (Recall Day 5, Cold Recall Day 10, Interleaved Day 6, Pre/Post Diagnostic).
→
You see the source sheet
Step 2 · Teacher
Names + answers are visible. Claude Haiku adds a first-pass score (0 / 0.5 / 1 per question, with a rationale). You can override any score by typing in the Score column.
→
Step 3 · Researcher
Researchers see the Export
A separate Researcher Export sheet shows the same rows with a stable S-XXXX token in place of each student's name. First name, last initial, and team data drop out.
🔒
The Roster stays private. A separate sheet (the Roster) holds the name → token mapping. Only the program admins can see it. If the Researcher Export is ever shared with the wrong person, the token alone can't be linked back to a student without the Roster. The same student keeps the same token across every export — so researchers can track growth over time without ever seeing who's who.

Practically: grade what you want in the Score column on each source sheet — that's the number researchers see. Leave it blank and the AI's total flows through. Either way, the per-question AI scores and rationales reach the Researcher Export so the research team can analyze where students struggled, not just the final grade.
