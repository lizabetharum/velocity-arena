The Day Spine

One page per day. Every activity boiled down to the three things you actually do while standing in the room — the move, the mistake to catch, and how it closes. The full facilitator notes stay as your prep-the-night-before backup; this is the card you hold during class.

The whole program is one question

How can you use data, equations, and code to build a robot athlete that wins on math, not luck?

The loop — every match day is the same 4 steps

Predict→ Run→ Gap→ Recover The math changes each week. The loop never does. Learn the loop, not 16 separate days.

If you're underwater, protect these five

  1. Predict before each match
  2. Gap sentence after each match
  3. Loss recovery after every loss
  4. Students explain the math — not you
  5. ENDS closure to end the day

How to read a card
